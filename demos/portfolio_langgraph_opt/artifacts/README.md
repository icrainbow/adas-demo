# Portfolio LangGraph Optimization - Visualization Artifacts

This directory contains Pareto frontier analysis and visualization artifacts for the LangGraph topology search results.

## Files

### Generated Artifacts

1. **`pareto.md`** - Comprehensive markdown analysis report
   - Summary of candidates evaluated
   - Key configuration comparisons (baseline, best, cheapest Pareto)
   - Trade-off analysis paragraph
   - Full Pareto frontier member table

2. **`pareto.png`** (requires matplotlib) - Token-based Pareto plot
   - X-axis: Average Total Tokens
   - Y-axis: Average Coverage
   - Shows all candidates, Pareto frontier, baseline, and best

3. **`pareto_cost.png`** (requires matplotlib) - Cost-based Pareto plot
   - X-axis: Cost per Case (USD)
   - Y-axis: Average Coverage
   - Same as token plot but scaled to real-world costs

### Placeholder Files (if matplotlib unavailable)

- **`pareto.png.txt`** - Description of what the token plot would show
- **`pareto_cost.png.txt`** - Description of what the cost plot would show

## How to Generate Visualizations

### Prerequisites

```bash
pip install matplotlib
```

### Generate Plots

```bash
# Using default settings
python demos/portfolio_langgraph_opt/scripts/make_pareto_viz.py

# Custom input and token price
python demos/portfolio_langgraph_opt/scripts/make_pareto_viz.py \
  --input demos/portfolio_langgraph_opt/outputs/results_v11_pareto_smoke.json \
  --output-dir demos/portfolio_langgraph_opt/artifacts \
  --token-price 0.02
```

### Command-line Options

- `--input`: Path to results JSON file (from portfolio_search.py)
- `--output-dir`: Directory for output artifacts
- `--token-price`: Token price per 1k tokens in USD (default: 0.01)

## Pareto Frontier Definition

A candidate **A** dominates candidate **B** if:
- `tokens_A ≤ tokens_B` AND `coverage_A ≥ coverage_B`
- AND at least one inequality is strict

The Pareto frontier consists of all non-dominated candidates.

## Interpretation Guide

### When to Choose Baseline
- Operating at massive scale (cost-sensitive)
- Coverage threshold: 35-40% is acceptable
- Budget constraints are primary concern

### When to Choose Best
- Quality is critical requirement
- Can afford 3x token cost premium
- Need 40%+ coverage
- Dealing with high-stakes decisions

### When to Explore Pareto Frontier
- Need to balance cost and quality
- Want to understand efficiency frontier
- Looking for "sweet spot" configurations
